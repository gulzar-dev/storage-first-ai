# Storage-First AI 🧠💿

A high-intelligence, autonomous AI agent designed to run on **low-end hardware (8GB RAM, No GPU)** by prioritizing storage-based memory over massive neural weights.

## 🚀 Key Features
- **Storage-First Memory:** Learns by writing permanent `.json` skills to your hard drive.
- **Compute Credit Economy:** An internal "survival" system that forces efficiency.
- **Dynamic Code Architect:** Generates custom Next.js + Tailwind UI code based on specific requirements.
- **Style Intelligence:** Automatically selects design palettes (Coffee, Law, Tech, etc.) based on brand identity.
- **Deep Search:** Zero-RAM retrieval using system-level `grep`.
- **Autonomous Research:** Identifies ignorance and researches the web to master new skills.

## 🛠️ Quick Start

### 1. Clone & Install
```bash
git clone https://github.com/gulzar-dev/storage-first-ai.git
cd storage-first-ai
pip install -r requirements.txt
```

### 2. Run the Agent
Ask the AI to do anything from its skill set:
```bash
# Check system health
python3 storage_agent.py "How is my system health?"

# Build a website
python3 storage_agent.py "Create a landing page for a coffee shop with pricing and contact form"

# Use the developer kit
python3 storage_agent.py "Initialize a git repo for MyProject"
```

## 🏗️ Architecture
Inspired by **ClawWork** (Economic Survival) and **Vercel Knowledge Agent** (Filesystem-as-Context), this project turns your local hard drive into the AI's "Context Window."
